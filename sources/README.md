# Sources Archive

This directory contains local copies of the sources most important to the project.

## `papers/`
Primary technical literature currently used in the reports and implementation.

- `angelopoulos_bates_gentle_intro_arxiv_2107.07511v6.pdf`
  - marginal coverage;
  - split conformal;
  - APS tutorial;
  - class-conditional/group-balanced coverage;
  - practical calibration guidance.

- `romano_sesia_candes_valid_adaptive_coverage_arxiv_2006.02544v1.pdf`
  - adaptive conformal classification;
  - generalized inverse-quantile conformity scores;
  - approximate conditional coverage motivation;
  - split-conformal calibration.

- `irvin_et_al_chexpert_AAAI_2019.pdf`
  - CheXpert dataset;
  - 14 observations;
  - report-based labeler;
  - uncertainty labels;
  - validation/test reference standards.

Vovk (2012) is currently linked in `LINKS.md` rather than stored locally. Add the PDF here if you download it.

## `coursework/`
University assessment criteria, project-plan examples and preserved requirement notes. These guide format and assessment rather than providing scientific evidence.

## Citation rule
Do not cite the course examples as scientific sources. For technical claims, cite the primary research papers in `literature/references.bib`.
